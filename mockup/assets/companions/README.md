# Chibi companion artwork

Generated with the built-in imagegen tool, with transparent backgrounds. These two local atlases each have three equal-width columns. The mockup selects each character through CSS background positioning and adds simple CSS movement; the images are not full multi-frame animation sheets.

- `chibi-trio.png`: Naruto, Sasuke, Sakura, left to right.
- `chibi-trio-2.png`: Luffy, Gojo, Anya, left to right.

## Prompt: chibi-trio.png

Create a clean transparent-background horizontal character sprite atlas for a small anime study companion website widget. Exactly three full-body chibi characters in THREE EQUAL WIDTH COLUMNS in one single horizontal row. Left Naruto Uzumaki: spiky golden blond hair, blue eyes, whisker cheek marks, ninja forehead protector, orange and black ninja outfit, cheerful friendly expression. Center Sasuke Uchiha: spiky black hair, dark eyes, dark blue high collar top, pale shorts, ninja sandals, calm friendly expression. Right Sakura Haruno: pink short hair, green eyes, red sleeveless ninja outfit, friendly expression. Each has a large adorable head, tiny body, short limbs, balanced standing pose with one small hand waving as a helpful learning companion. All face front, same scale, consistent polished hand-drawn 2D anime chibi illustration, clean ink lines, soft cel shading, crisp silhouette, no pixel art, no photorealism. Put each character FULLY inside its own equal third of the image with generous transparent margins, same feet baseline. All three are separated, no overlap. Every character includes head and feet and hands without cropping. No labels, text, speech bubbles, scenery, ground, shadow, card backgrounds or frame. Actual alpha transparency across entire background. This is one sprite atlas asset, not a UI mockup.
